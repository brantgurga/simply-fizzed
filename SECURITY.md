# Security Policy

## Supported Versions

Only the latest `main` branch is currently supported. Fixes are applied to
`main`, and older commits or releases do not receive security updates.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest `main`  | :white_check_mark: |
| Anything else  | :x:                |

## Reporting a Vulnerability

If you discover a security issue that is not appropriate to disclose in the
public issue tracker, please report it privately.

Send an e-mail to [brant@gurganus.name](mailto:brant@gurganus.name) with the
subject line prefixed with:

```text
Security Issue in simply-fizzed:
```

Please include as much detail as you can so the issue can be reproduced and
resolved quickly, such as:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- Any relevant versions, configuration, or environment details.

You will receive a response acknowledging the report, and you will be kept
informed as the issue is investigated and addressed. Please avoid publicly
disclosing the issue until a fix has been released.
