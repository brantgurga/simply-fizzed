# Contributing

Contributions are welcome through GitHub pull requests.

## Before opening a pull request

- Run `npm run check:licenses`, `npm run typecheck`, `npm run lint`, and `npm test`.
- Keep the copyright and SPDX notice on every applicable source or configuration file.
- Explain the purpose of the change and add tests for changed behavior.

## Copyright assignment

External human contributors must read
[the copyright assignment](COPYRIGHT_ASSIGNMENT.md) and check its exact
attestation in the pull request template. The project cannot accept an external
contribution without that affirmation.

Git history and the pull request preserve contributor attribution. Accepted
contribution copyright is assigned to Brant Langer Gurganus and the contribution
is distributed with the project under AGPL-3.0-only.
